# User Records Dashboard

A simple and responsive user management dashboard built with **React.js**, **Material UI**, and **static JSON** as the data source. This project allows users to view, edit, and delete records efficiently in a styled table layout.

## 🚀 Tech Stack

- **React.js**
- **Material UI (MUI)**
- **HTML5**
- **JSON (as data source)**

## ✨ Features

- Responsive user records table
- View & delete user data
- Edit functionality by navigating to a dedicated edit page
- Styled using Material UI components
- Navigation using React Router
